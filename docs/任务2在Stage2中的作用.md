# 任务2在Stage2中的作用

## 连接B的数据
- **证据索引**：建立chunk_id到原文的映射，保留document_id、source_url等provenance信息
- **结构化字段**：区分正文原文与结构化字段拼接的文本，确保可回查
- **真实数据**：使用实际爬取的非遗数据，不编造片段

## 与A的证据判断
- **双通道校验**：确定性规则核对（批次/地区/类别）+ NLI模型校验
- **三分类标签**：SUPPORTED/PARTIALLY_SUPPORTED/UNSUPPORTED
- **置信分数**：0-1表示支持程度，非概率
- **理由说明**：提供简短判断理由

## 与E的溯源展示
- **证据片段**：提供可展示的原文片段
- **来源URL**：支持点击查看原始页面
- **异常处理**：对无依据事实提供降级提示
- **多引用支持**：支持多个chunk共同提供证据

## 与任务1、任务3的关系
- **任务1（实体归一）**：不直接依赖，但共享provenance数据
- **任务3（Benchmark）**：提供gold_evidence验证的参考实现
- **职责边界**：B负责证据溯源和校验，A负责综合判断，E负责展示

## 核心价值
- **可信度提升**：验证AI回答是否被原文支撑
- **错误识别**：识别幻觉和错误引用
- **透明度增强**：提供可追溯的证据链
- **质量保证**：为后续实验提供可靠的数据基础
