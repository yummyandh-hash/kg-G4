# Stage2 B模块优化说明文档

## 优化概述
本阶段对B模块的实体归一功能进行了全面优化，实现了三层融合实体归一策略，提升了实体识别的准确性和可靠性。

## 优化内容

### 1. 三层融合实体归一策略
实现了基于规则词典、语义相似度和图谱约束的三层融合实体归一：

#### 第一层：规则词典（非遗俗称、别名）
- 建立了非遗相关实体同义词词典（NON_INTANGIBLE_RULES）
- 包含剪纸、皮影戏、京剧、昆曲等十大门类的常见俗称和别名
- 例如："陕北剪纸"和"陕西民间剪纸"会被识别为同一实体

#### 第二层：语义相似度计算
- 使用SequenceMatcher算法计算字符串相似度
- 实现了merge_equivalents函数，将相似度高于0.88的实体自动合并
- 支持同义词和近似词的识别

#### 第三层：图谱地域/门类约束辅助消歧
- 基于上下文信息（地区、机构、类别）进行实体类型纠正
- 防止将地名误判为保护单位，或反之
- 考虑非遗项目的地域特征和门类属性

### 2. 实体候选库生成优化
- 实现了EntityCandidate数据类，标准化输出格式
- 自动计算置信分数（基于实体合并数量和信息完整性）
- 支持来源文档追踪，便于溯源和验证

### 3. 代码结构优化
- 模块化设计，便于维护和扩展
- 添加了详细的文档字符串和注释
- 实现了主函数，可直接从清洗后的文档生成实体候选库

## 技术实现细节

### 核心算法
```python
# 三层融合决策流程
1. 规则词典匹配（优先级最高）
2. 语义相似度计算
3. 图谱约束辅助消歧
```

### 置信度计算
置信度基于以下因素：
- 实体合并数量（每增加一个同义实体增加0.1置信度）
- 类别信息完整性（+0.2）
- 地区信息完整性（+0.2，上限1.0）

### 输出格式
生成符合要求的entity_candidate.json，包含：
- 标准实体名
- 全部别名
- 所属地域/门类
- 置信分数
- 来源文档ID

## 性能优化

### 处理效率
- 使用set数据结构优化重复检测
- 批量处理文档，减少I/O操作
- 内存优化，适合大规模数据处理

### 准确性提升
- 三层策略显著减少了实体误判
- 置信度机制帮助识别低质量匹配
- 上下文感知提高了消歧准确性

## 使用方法

### 基本用法
```python
from entity_resolver import generate_entity_candidate_file

# 从清洗后的文档生成实体候选库
generate_entity_candidate_file(documents, "data/entity_candidate.json")
```

### 参数调整
- 相似度阈值：可调整merge_equivalents函数的threshold参数
- 置信度权重：可修改confidence计算逻辑
- 规则词典：可扩展NON_INTANGIBLE_RULES
