# 历史嵌套仓库入口

原 Gitee 基线将本目录记录为 Git gitlink，指向提交 7eb0eebb4bc8471077744e4baed0c378058e0dc1，但没有 .gitmodules，也没有可核验的子仓库地址。父仓库 bundle 不等于已经备份子仓库本体。

该不完整指针会使 GitHub Actions 的 checkout / 凭据清理失败。仓库治理将当前入口改为本说明目录，不伪造子仓库 URL、来源文件或新的实现。

原 gitlink 仍可在迁移基线与历史提交中核对。此改动没有重写或删除成员历史；其他原分支按原样保留。若以后取得正确远端和完整子仓库，应通过独立 PR 补充并验证。

当前可见的数据采集代码请查看根目录 crawler/ 与 data/。本目录不作为已可运行的子模块交付。
