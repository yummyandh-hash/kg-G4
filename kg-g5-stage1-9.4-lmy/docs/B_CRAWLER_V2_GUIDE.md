# B 成员爬虫 V2 使用指南（全类别自动化爬取）

## 概述

爬虫 V2 相比旧版本的主要改进：
- ✅ 自动获取所有类别（十大门类）的 category_id，不再需要手动 F12 复制
- ✅ 按类别分目录存储，避免数据覆盖
- ✅ 支持断点续爬，类别内已下载的页会自动跳过
- ✅ 完整的错误处理和日志记录

## 运行步骤

### 第 1 步：运行新版爬虫
```bash
python crawler/ihchina_crawler.py
```

### 第 2 步：查看爬取结果
- 原始数据：`data/raw/category_16/page_000001`（按类别分目录）
- 总 manifest：`data/raw/manifest.jsonl`（合并所有类别）
- 类别 manifest：`data/raw/category_16/manifest.jsonl`（单个类别的记录）

### 第 3 步：清洗数据
```bash
python crawler/clean.py
```

### 第 4 步：分块
```bash
python crawler/chunk.py
```

## 配置说明

### 自动类别获取策略

爬虫会自动尝试 6 种策略获取类别列表：

1. **策略1（默认）**：从主页 HTML 中提取 JS 变量（成功率最高）
2. **策略2**：从下拉菜单 HTML 提取（当页面结构简单时）
3. **策略3**：调用可能的 API 接口（如果存在）
4. **策略4**：从项目详情页链接提取
5. **策略5**：从分页组件获取
6. **策略6**：手动指定（前 3 个策略都失败时）

如果自动获取失败，脚本会提示你手动指定类别。

### 参数配置

在 `crawler/ihchina_crawler.py` 中修改：

```python
# 单类别爬页数（None=全部页数，或指定具体数字如 10）
MAX_PAGES_PER_CATEGORY = None  # 改成 10 可以测试爬取效果

# 请求间隔秒数
REQUEST_INTERVAL = 1.0

# 超时时间
TIMEOUT = 15
```

## 故障排查

### 1. 自动获取类别失败
- 现象：爬虫提示"自动获取类别失败"
- 解决方法：
  1. 打开网页 F12，查看真实的 category_id 和名称
  2. 修改脚本底部：
     ```python
     categories = [(16, "传统美术"), (17, "传统音乐"), ...]  # 手动指定
     ```

### 2. 某类别返回空数据
- 现象：类别目录下只有 115 字节的文件
- 解决方法：
  1. 确认页面该类别确实有数据
  2. 检查网络代理或防火墙是否干扰
  3. 更换请求间隔（比如从 1.0 增加到 2.0）

### 3. 数据解析失败
- 现象：clean.py 说解析出 0 条记录
- 解决方法：
  1. 查看原始文件 `data/raw/category_16/page_000001` 的内容
  2. 如果不是 JSON 格式，需要修改 `parse_raw()` 函数

## 性能建议

1. **首次运行**：建议设置 `MAX_PAGES_PER_CATEGORY = 1` 先测试
2. **全量爬取**：确认爬虫正常工作后，改成 `None`
3. **调试模式**：临时降低 `REQUEST_INTERVAL`（但不能低于 0.5 秒）

## 向后兼容

- 新爬虫生成的原始数据格式完全兼容旧的 `clean.py` 和 `chunk.py`
- 如果已有旧格式数据，删除 `data/raw/` 重新运行即可

## 注意事项

1. 不要设置 `REQUEST_INTERVAL < 0.5`，礼貌爬取，避免被反爬
2. 如果某个类别爬取失败，脚本会继续下一个类别，不会中断
3. 断点续爬功能：重新运行不会重复下载已存在的页面
