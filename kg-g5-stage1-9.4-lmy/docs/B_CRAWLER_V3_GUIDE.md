# B 成员爬虫 V3 使用指南（子项详情抓取）

## 概述

爬虫 V3 相比 V2 的主要改进：
- ✅ **新增子项详情抓取**：对每个项目请求详情页，获取子项信息
- ✅ **预览模式**：仅处理少量数据，控制台输出，用于调试
- ✅ **完整模式**：全量爬取并保存到文件
- ✅ 子项字段：在项目数据中新增 `sub_items` 字段，包含子项列表

## 运行步骤

### 第 1 步：开启预览模式（推荐）
```bash

```

运行：

## 配置说明

### 模式切换

```python
# 预览模式（调试用）
PREVIEW_MODE = True
# 效果：
# - 只处理前2个类别
# - 每个类别只处理前3个项目
# - 不生成任何文件
# - 输出控制台日志，方便核对字段

# 完整模式（正式用）
PREVIEW_MODE = False
# 效果：
# - 处理所有类别
# - 处理所有项目
# - 保存完整数据到 data/raw/
```

### 其他参数


## 故障排查

### 1. 预览模式显示无子项
- 检查项目详情 URL 是否正确
- 可能子项数据在 HTML 中，需要在 `fetch_detail_page()` 函数调整解析逻辑

### 2. 项目抓取失败
- 查看控制台错误信息
- 确认项目 ID 格式是否正确
- 单个项目失败不会影响整体爬取

### 3. 预览模式和完整模式输出不一致
- 检查 `PREVIEW_MODE` 设置是否正确
- 确保重启脚本后参数生效

## 注意事项

1. **先预览再正式**：务必先用预览模式测试，确认子项字段正确再正式爬取
2. **项目 ID 格式**：有些项目可能是中文编号（如"Ⅱ-18"），确保详情页 URL 正确
3. **请求频率**：详情请求间隔（2秒）比列表请求间隔（1.5秒）长，避免给服务器压力
4. **容错处理**：单个项目失败不会中断整体爬取，会继续处理下一个项目

## 向后兼容

- 新增的 `sub_items` 字段不影响原有字段
- `clean.py` 和 `chunk.py` 无需修改
- 原始数据仍保存在 `data/raw/category_XX/` 目录下

## 性能建议

1. 首次运行使用预览模式
2. 完整模式可能需要较长时间（1557个项目 × 平均3个子项 = 4600+次详情请求）
3. 建议在非高峰时段运行完整模式
