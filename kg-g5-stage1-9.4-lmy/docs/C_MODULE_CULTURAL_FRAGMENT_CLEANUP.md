# C 模块文化要素脏数据清理说明

## 问题

在 C 模块的文化要素抽取中，少量句子残片会被误抽为 `CulturalElement`，例如：

- `共有小曲`
- `础上组建上海木偶皮影`
- `多则百人舞`
- `东民间乐曲`
- `南岸彝族舞`
- `塘夏尔巴歌`
- `岭南民间舞`

这些结果不是规范实体，而是正文中的说明语句、动词短语或截断片段。

## 处理方式

1. 源头抑制：强化抽取提示词
   - 明确 `CulturalElement` 只能是名词或名词短语。
   - 直接禁止输出完整句子、动词短语、解释句和过渡句。
   - 对 “一种是以舞...”“改革了秧歌...”“在村寨以外举行” 这类片段给出负例。

2. 规则后处理：扩展文化要素负样本规则
   - 增加更完整的句式前缀黑名单，如 `共有`、`多则`、`受`、`使`、`博采`、`融入`、`展现` 等。
   - 增加更完整的描述性标记黑名单，如 `民间`、`组建`、`吸取`、`吸收`、`保留`、`形成` 等。
   - 同时维护一份核心文化词白名单，优先保留 `民间故事`、`摆手舞`、`目连戏` 这类规范短语。

3. 增加原文上下文判断
   - 对 `舞 / 歌 / 戏 / 曲 / 影 / 木偶 / 皮影` 这类容易被截断的候选词，检查原文右侧是否还连着 `蹈 / 舞 / 曲 / 戏 / 剧` 等续写字符。
   - 如果候选其实是更长词组的一部分，则直接丢弃。

4. 质量统计加告警
   - 在 `quality_report.json` 中新增 `cultural_fragment_count` 和样例。
   - `check_sample.py` 同步输出该风险数，方便快速验证。

## 验证方式

1. 运行样本检查：

```bash
python check_sample.py
```

2. 观察两点：

- 抽样实体中不再出现上述碎片；
- `文化碎片风险数` 为 `0`。

## 结果

本次修改把文化要素抽取从“宽松召回”收回到“偏精确优先”
